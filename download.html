If Windows says "Windows protected your PC"

Windows shows this blue screen for new apps that are not yet code-signed. Clutch is one of them for now. To continue:

  1. Click More info.
  2. Click Run anyway.

This message will appear until the app is code-signed. Only download Clutch from the official GitHub release linked on this page; if you got the file anywhere else, delete it and download it again from here.
